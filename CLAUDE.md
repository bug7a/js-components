## What this is

**OzdenUI**: UI components, samples and app templates built on **basic.js** (`basic/basic.js`), a small, dependency-free library by Bugra Ozden: the whole UI in plain JavaScript, DOM objects made directly, no HTML markup, no CSS authoring, no virtual DOM. Apache 2.0.

There is **no build system, package.json, bundler, linter or test runner**. Every page is a standalone `.htm` file that loads scripts with `<script src>`; open it in a browser. Live Server is on port 5505 (`.vscode/settings.json`).

## Core basic.js concepts

- **Startup**: basic.js creates the global `page` (a `MainBox`), then calls the global `start()` if there is one (older pages: `window.onload`). A global `loop()` runs every 1000 ms (`setLoopTimer(ms)`).
- **Constructors**: `Box`, `Label`, `Button`, `Input`, `Icon`: `(left, top, width, height)`, the props object **last** (`Label({ text: "Hi", fontSize: 16 })`, `Box(0, 0, "100%", "100%", { color: "red" })`). `obj.props({...})` after creation; the DOM element is `obj.elem`.
- **`that`**: the last object made (`that.css = {...}` right after it); `prevThat` the one before it.
- **`page` never scrolls** (`body { overflow: hidden }`). Content taller or wider than the screen goes into a full-screen box that scrolls, with a `ScrollBar` (an older page without it stays as it is). Sample and template pages that stack content vertically use `comp/scroll-area.js` (see `_empty-project-template.htm`; load `basic/scroll-bar.js` too, for the bar):
  ```js
  ScrollArea({ align: "center top", gap: 20, padding: 40 }); // scrollX: 1 for horizontal too
      // ... page content
  endGroup();
  ```
  It is the long form of a page without `comp/` (the tutorial pages of `01-`): `const pageBox = startBox(0, 0, "100%", "100%", { color: "transparent", scrollY: 1 });`, a `VGroup` with `height: "auto"` (so the content can be taller than the box), `endGroup(); endBox();`, `ScrollBar({ scrollableBox: pageBox });`.
- **Only a Box holds other objects** (`Box`, `startBox()`, `HGroup` / `VGroup`). Not `Button`, `Label`, `Input`, `Icon`: an object inside a button bubbles its mouse events to it. An overlay goes into the same box as a sibling, `position: "absolute"`, with the target's left/top/width/height (`box.btnSendCover` in `comp/form.js`).
- **Implicit containers**: new objects go into the current default container; `startBox()`/`endBox()` and `HGroup`/`VGroup` … `endGroup()` push and pop it. **Every start call needs its end call** (basic.js warns about the missing ones).
- **Groups** (`HGroup`, `VGroup`: flexbox; `AutoLayout` / `endAutoLayout` are the old names: not in new code): `flow`, `align: "left top"`, `gap`, `padding` (a number or `[x, y]`), `wrap: 1`, `justify`, `stretch: 1` (the items without a width / height fill the group across: `css: { alignItems: "stretch" }` in short), `hug: 1` (width and height `"auto"`). A group is 100% × 100% by default. **`hug: 1` in new code**; `fit: 1` is its old name: don't "fix" pages that use it. **`stretch: 1` in new code** (a `comp/` file with it needs basic.js v26.11.10); the old `css: { alignItems: "stretch" }` stays where it is: don't switch it.
- **Common props**: `color` (background), `textColor`, `border`, `borderColor`, `round`, `opacity`, `visible`, `clickable`, `clipContent`, `scrollY`. Alignment: `center()`, `centerBy(obj)`, `aline(obj, "right", space, "center")`.
- **Events**: `obj.on("click", (self, event) => {})` returns a remover. Resize: `obj.onResize(fn)`, `page.onResize(fn)`. **Motion**: `obj.setMotion("left 0.3s, opacity 0.2s")`, then change the properties.
- **Helpers**: `Black(a)`, `White(a)`, `Alpha(color, a)`, `println`, `random`, `basic.storage.save/load`, `waitAndRun(timer, fn, ms)` (debounce), `withPageZoom`, `basic.num()`, `basic.str()`, `basic.isMobile()`, `basic.go(url)`, `basic.twoDigitFormat()`. The old globals `num`, `str`, `isMobile`, `go`, `twoDigitFormat`, `createBox`, `createButton`, `createLabel`, `createImage`, `createIcon`, `createInput`, `createTextBox` are gone (`basic.createBox()`... stay): old code that calls them needs that change.

## Writing a component

Follow `_component-template.js` or a component such as `comp/smart-button.js`:

```js
"use strict";
const MyCompDefaults = { width: 240, height: 70, labelText: "", onClick: function (self) {}, style: { box: {}, label: {} } };

const MyComp = function (params = {}) {
    basic.applyStylePackage(params, MyComp.styles, MyCompDefaults); // when it has style packages
    mergeIntoIfMissing(params, MyCompDefaults);   // deep-fills missing keys (mutates params)
    let box = startObject(params);                // container box; children created below go inside it

    // *** PRIVATE VARIABLES / FUNCTIONS
    // *** PUBLIC VARIABLES / FUNCTIONS  → box.setX = function (v) { box.x = v; box.child.text = v; };

    // *** OBJECT VIEW  → build children (box.label = Label({...}), groups, etc.)
    // *** OBJECT INIT CODE  → box.on("click", ...), box.listenTo(window, "keydown", fn), box.after(300, fn), initial setters
    return endObject(box);                        // closes the container and makes `that` === box
};
```

- **Style packages** (`styleName`, `Comp.styles`): the themes of the kit are `light` (the default) / `dark` (the general look), `minimal` / `minimalDark` (small, made of lines: `_designs/minimal-theme.htm`, 28 px controls, 13 px text, no fill or shadow of its own), `ozden` / `ozdenDark` (the user's experimental designs). A new component has at least `light` and `dark`; others may exist besides them. An older component keeps its names: `classic` is the old name of `light` and still works, except where `classic` is another look (ItemList, Toggle, TinyTable, ActionButton, Notice, ScrollingText; TextField: the old name of `modern`). `basic.applyStylePackage()` copies `params.style`; a package with its own `style` key is a package of params (its other keys fill the params). Older components with three lines of their own keep them until they are touched.
- **A minimal package** is `X.createMinimalStyle(X.MINIMAL_COLORS)` / `X.MINIMAL_DARK_COLORS` (the text on the ink: `onInk`), and the component goes into `MinimalAccent.COMPONENTS` (`comp/minimal-accent.js`): the packages in a color of the page are made from them.
- **`animated` param:** its motions follow `context/basic-js-animated-rules.md` (model: `comp/search-input.js`): `animated: 0` changes nothing, no motion at the first view, 0.25s `cubic-bezier(0.2, 0.8, 0.2, 1)`, only `transform` / `opacity` / `box-shadow` (exceptions in that file), CSS transitions, off with `prefers-reduced-motion`, one state + `paintMotion()`.
- `startObject(defaults, params)` (the two-argument form) does the same merge; params win in both forms.
- **Cleaning up:** `remove()` removes every basic.js object inside, parents first. Use `box.listenTo(window, ...)`, `box.onPageResize()`, `box.after()` / `box.every()`, `box.own(obj)`: `remove()` cleans them. **A component never defines `destroy()`.** Only for what basic.js can not know (a static list, an observer, objects made directly on `page`) it overrides `remove()`: `const superRemove = box.remove; box.superRemove = superRemove;` then `box.remove = function () { if (!box) return; /* cleanup */ superRemove.call(box); box = null; };` (the local `superRemove`: a child component overwrites `box.superRemove`, and calling that would loop forever). A removed object is never re-added. Also: `box.onHoverChange()`, `box.setFocusRing()`, the props `role` / `aria` / `tabIndex` (not `elem.setAttribute`), `basic.isOn()`, `basic.addCss()`, `createIn()` returns its function's result. `ScrollBar` keeps its own `destroy()`.
- **The version a component needs:** a copy of a `comp/` file must go with a basic.js at least as new as the one it was written for (the list per file: "Notes moved from CLAUDE.md" in `context/repo-map.md`).
- Every default becomes a public property on `box`; after creation, values change through `setX()` methods, not getters / setters. A default must not be named like a basic.js setter (`html` sets `innerHTML`, `zoom`, `text`, `color`, `title`, `visible`...): use names like `htmlText`, `scale`.
- Inherit with `startExtendedObject(ParentComp, params)` … `endExtendedObject(box)` (`comp/email-field.js`). The child loads after its parent.
- **Param names** follow the table of `context/basic-js-code-rules.md` (`test/components-test.htm` checks the defaults and the setters against it; 9: `value`, `required`, `...Text`, `show...`, `...IconFile`, `onChange(self)`, a setter with the whole name of its param: `setTitleText`...). A param, an event or a component that gets a new name changes in the same job everywhere in the repository (`comp/`, the samples, the templates, the pages); no old name is kept (the bridge of 2026-11-08 that did it for a day: `context/repo-map.md`, "Parameter names").
- PascalCase names with a matching `XxxDefaults`. A default icon is an SVG inside the file (`"data:image/svg+xml;utf8," + encodeURIComponent('<svg ...>')`, `comp/password-field.js`): a copy of the file needs no picture. Other assets in a sibling folder with the same name.
- Files keep the house header: `/* Bismillah */` on the first line (a `.htm`: of its first script), name/version, and at its end the block of `_component-template.js`: `Started Date`, `Webpage`, then `Copyright 2020-2026 Bugra Ozden <bugra.ozden@gmail.com> (https://bug7a.github.io/)`, `Licensed under the Apache License, Version 2.0`, `SPDX-License-Identifier: Apache-2.0` (the samples of `01-` / `02-` have none: they are copied into other people's pages; Claude is named in the README and the catalog's footer, not in a header). It is the one comment with a date and a person. New comments are in English; an old Turkish comment changes when the code around it is touched. Keep the section markers (`// *** PUBLIC FUNCTIONS:`, `// BOX:`, `// LABEL:`, …).

## Conventions and gotchas

- **Copies and scripts:** `./_make-standalone.sh <project-folder>` makes a project work outside the repo in `_dist/<name>/` (the project folder is not changed; `--in-place`, `--separate`, `--gzip`, `--list`: options in `context/repo-map.md`). `./_make-template-repo.sh` writes the mobile templates into the local clone of `javascript-mobile-app-template` and never commits. Template folders may hold **copies** of the library and components (`ozden-panel/common/ui-standards.js`, `todo-app-example/basic/`): fixing `basic/` or `comp/` does not update them. The two sites of `03-webpages` load their own `comp/*.min.js` (`_sources.txt`): their pages keep the param names of those copies until the copies are refreshed.
- **No `.min.js` next to a component source.** Pages load `comp/name.js`; a component's `.min` file exists only in a copy that leaves the repo (`_make-standalone.sh`, `_update-copies.sh`). The library keeps its twins (`basic.min.js`, `basic.min.css`, `scroll-bar.min.js`): after editing their source, `./_make-min-js.sh --build basic/basic.js` (no arguments: lists the stale twins; file dates, so a listed file is not always really stale).
- Script order: `basic.css` and `basic.js` first, then `ui-standards` if used, then the components (a child after its parent), then the page code. Paths are relative to the `.htm` file (samples `../basic/`, templates `../../basic/`).
- An inline `<script>` in a `.htm` file never contains a closing tag as plain text (in a string or a comment), even `</body>`: write `<\/body>` (Live Server puts its reload script before the first body end tag in the file).
- An `.svg` file has one `</svg>`: a drawing put on a larger canvas goes into a `<g transform>`, not into an inner `<svg>` (Live Server puts its reload script before every `</svg>` and cuts the file at the length of one, so the picture is not drawn).
- **A box that scrolls uses `scrollY = 1` / `scrollX = 1`, never `overflow...: "auto"` in `css`**: the props also make it clickable, so the wheel works. Each sets only its own axis; put it after a `css = {...}` that would overwrite it.
- `basic.css` gives every box `pointer-events: none` and the page `user-select: none` (inherited): a raw HTML element in a box (a `<textarea>`) needs `pointer-events: auto; user-select: text`.
- A Box with `height: "auto"` does not grow with basic.js children (absolutely positioned): use a group, or a child wrapper with `position = "relative"`.
- `setDefaultContainerBox(box)` is not part of the start/end stack. To make objects in an existing box, `createIn(box, function () { ... })`. Children made while a group is hidden are not flex items: hide the group after them. `visible: 0` is undone by a later `elem.style.display`: set the display first. A flex group with `width: "auto"` in a scrolling Box does not grow: give it `width: max-content`.
- **`box.width` / `box.height` never read "auto" or "100%"** (they give the measured number): a component reads such a value from `params` before `startObject()` (`const isAutoHeight = (String(params.height) === "auto")`).
- **A group clips its content** (`clipContent: 1` by default): a thing that moves out of its box (a lifting button, a growing picture, a glow, a focus outline) is cut. Give such groups `clipContent: 0`; keep 1 only where cutting is the point.
- **A popup that opens from a field** (a list, a menu) goes over a Dialog or a SidePanel: `basic.zIndexAbove(obj, minimum)` when it opens, as every list and menu of `comp/` does.
- On a page fitted with `page.fit()`, the components made for screen px take a `scale` param (default `basic.uiScale`; set it to `1 / page.zoom`).
- Page and component helpers are global: never name them like basic.js globals (`Box`, `Label`, `random`, `println`...). Prefer `MyPage.createButton`.
