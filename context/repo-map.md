# Repo map: every folder in detail

The full directory map of the JS-Component Kit (moved out of CLAUDE.md on 2026-11-01, the user: CLAUDE.md keeps a short map). Read the row of a folder before working in it: its history, its rules and the details of every component are here.
Add new details here, not in CLAUDE.md.
