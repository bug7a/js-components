Claude Code Komutları

Sık kullanılan komutlar ve ne işe yaradıkları. Tam liste için sohbet kutusuna /help yazın. VS Code panelinde bazı komutlar terminal sürümünden farklı olabilir.

Kod kalitesi ve inceleme

KomutNe yaparNe zaman
/simplify [hedef]Değişen kodu tekrar, sadeleştirme, verimlilik ve doğru seviyede çözüm açısından inceler, düzeltmeleri uygular. Hata aramaz.Bir bileşeni bitirince, commit'ten önce
/code-review [seviye] [hedef]Değişiklikte hata arar. Seviye low…max; ultra bulutta çok ajanlı derin inceleme yapar (ücretli). --fix ile bulguları uygular.Önemli bir değişiklikten sonra
/security-reviewBekleyen değişikliklerde güvenlik açığı arar.Form, servis, dışarıya veri gönderen kod yazınca

Bu repo için akış

  1. Bileşeni yaz ve örnek sayfada dene.
  2. Commit et (sonraki değişiklikler geri alınabilsin diye).
  3. /simplify comp-m4/dosya.js — yeni dosyalar git diff içinde görünmez, yolu verin.
  4. /code-review
  5. test/components-test.htm ve örnek sayfayı tekrar çalıştır (sekme başlığı ALL PASS olmalı).
  6. Tekrar commit et.

/simplify için ipuçları

  • Dört inceleme ajanı paralel çalışır: tekrar kullanım, sadeleştirme, verimlilik, doğru seviyede çözüm. Sonra bulgular birleştirilip uygulanır.
  • Dosyaları doğrudan değiştirir: önce commit edin, sonra sonucu git diff ile görün.
  • Normal bir istekten daha fazla token harcar: her küçük değişiklikten sonra değil, bir bileşeni bitirince bir kez çalıştırın.
